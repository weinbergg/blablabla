# Библиотека blablablarden

Лаконичный каталог литературы по философии, истории и математике. Публичная
часть содержит поиск, категории и подкатегории; закрытая панель позволяет
загружать, редактировать и удалять материалы.

## Запуск

Требуется Node.js 18.18+.

```bash
npm install
cp .env.example .env.local
npm run dev
```

Сайт откроется на [http://localhost:3000](http://localhost:3000), панель
управления — на `/admin`.

Если `.env.local` не создан, локальный пароль администратора:
`blablablarden`. Перед публикацией обязательно задайте собственные
`ADMIN_PASSWORD` и `SESSION_SECRET`.

## Хранение данных

- Метаданные: `data/library.json`
- Загруженные файлы: `public/uploads/`
- Максимальный размер файла: 25 МБ
- Форматы: PDF, EPUB, MOBI, DJVU, TXT, DOC, DOCX

Текущая реализация рассчитана на локальный запуск или VPS с постоянным диском.
Для serverless-платформ (например, Vercel) загрузки нужно перенести в S3/R2, а
метаданные — в постоянную базу данных.
