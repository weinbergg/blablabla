# Шрифты для экспорта PDF

`pt-sans-regular.ttf` / `pt-sans-bold.ttf` — шрифт PT Sans (ParaType), лицензия
SIL Open Font License 1.1, свободен для любого использования, в том числе
встраивания в генерируемые PDF. Файлы — полные (латиница + кириллица +
цифры/пунктуация), взяты из репозитория [google/fonts](https://github.com/google/fonts/tree/main/ofl/ptsans).

Используются только сервером (`lib/pdf-export.ts`) при генерации версии книги
«с пометками» — там нужен обычный `.ttf` с полным набором символов, а не
веб-оптимизированный `.woff`/`.woff2`, разбитый на латиницу/кириллицу по
отдельности (такие «половинки» не подходят: без цифр и пунктуации в
кириллическом подмножестве текст в PDF рендерился с пропущенными глифами).
