# Голосовые сообщения и дальнейший UX

## Голосовые: оценка перед отдельным этапом

Существующий путь подходит для хранения: `community_attachments` → проверка owner/parent → `channel_post` → защищённый `/api/community/files/[id]` с Range. Дублировать файлы или использовать публичную музыкальную библиотеку для частных записей нельзя. Сейчас в этом пути нет `audio` kind, нормализованной длительности и проверки аудиоконтейнера. Голосовые пока **не реализованы**, кнопка-заглушка не добавлялась.

Предлагаемый небольшой отдельный этап:

1. `MediaRecorder` + `getUserMedia({audio:true})`, запуск по кнопке. Выбирать MIME через `isTypeSupported` (WebM/Opus, MP4/AAC, при наличии Ogg/Opus), не определять по названию браузера. Для Safari обязательно проверять MP4; источники: [MDN MediaRecorder](https://developer.mozilla.org/en-US/docs/Web/API/MediaRecorder), [WebKit: MediaRecorder API](https://webkit.org/blog/11353/mediarecorder-api/). Отказ микрофона, отсутствие API, прерывание устройства — понятные состояния с повтором. Нужен HTTPS/localhost.
2. Локальные состояния: готовность → запись с таймером → остановка → `<audio controls>` preview → перезапись/удаление → явное добавление. Ограничение первой версии: 3 минуты, 10 МБ. Закрытие/unmount останавливает tracks и освобождает object URLs. До подтверждения вставки запись не публикуется.
3. Расширить существующий union kind и блоки версии 1 опциональным `audio`, без новой таблицы. Проверить совместимость старого рендерера перед откатом. MIME+magic недостаточно для определения длительности. Предпочтителен серверный `ffprobe` с жёстким timeout, лимитом входа и без сетевых протоколов, sandbox и временным каталогом. Он есть на текущем Mac, **наличие на production неизвестно**. Это дополнительная эксплуатационная зависимость, её не устанавливаем на VPS без согласованного этапа. Альтернатива — ограниченный проверенный контейнерный parser после отдельной оценки; доверять duration из клиента нельзя.
4. Сохранять прошедший проверку файл существующим upload/bind/access путём; блок получает серверную длительность/размер. Авторизация, дневная квота, draft privacy, удаление публикации и feature flags действуют как на другие вложения. Аудио появляется в существующей медиатеке как дополнительная категория.
5. Критическая приёмка: отказ/отзыв микрофона, retry, pause браузера, лишняя длительность/размер/подмена MIME, приватный draft и чужой файл, опубликованный Range/seek, скрытие и удаление; реальные iOS Safari и Android Chrome. До этого экспериментальный доступ только выбранным тестировщикам.

Это техническое предложение по требованию владельца «сначала предложи план» при изменении media pipeline. Платёжные механизмы и транскрибация сюда не входят.

## Локальные визуальные изменения этой итерации

Карточки книг с настоящими EPUB-обложками и метаданными; более компактная цитата в ленте, источник/автор/глава или раздел, переход к обсуждению. Панель вложений разделена по задачам, у фото есть порядок/подпись/удаление и lightbox, у файлов — размер/тип/скачивание, у видео — preview и ошибки с повтором. Личные комментарии переносятся отдельно от цитаты. Медиатека ведёт к контексту исходной записи.

Визуально просмотрены реальные снимки карточек/медиатеки/выбора пометки на 390/320 и исходные fullscreen читателей. В шапке канала обнаружено обрезание длинного русского слова рядом с аватаром: аватар на узком экране перенесён над названием, добавлено сжатие flex-элемента и перенос. Повторный browser-прогон на семи ширинах и в landscape прошёл, итоговые снимки просмотрены. Яркая обложка Вазари — исходное объявленное изображение внутри EPUB, не ошибка извлечения; файл не менялся.

## Предложения после стабилизации

| Изменение | Польза читателю | Сложность | Риск |
| --- | --- | --- | --- |
| Мобильный нижний лист действий для выделения | Меньше перекрытия текста и удобнее большой палец | Средняя | Нужны реальные selection handles iOS/Android |
| Явное «Отменить удаление блока» в редакторе | Быстро восстановить фото/цитату без окна подтверждения | Низкая | Согласовать с автосохранением |
| Поиск в медиатеке по книге/подписи | Быстро найти материал в длинном канале | Средняя | Индекс/нагрузка на SQLite; без дублирования данных |
| Выбор обложки владельцем издания | Качественные карточки при неудачной обложке EPUB | Средняя | Права редактирования/авторство; не менять исходный файл |
| Программа комнаты с текущей встречей и кратким итогом | Понятно, где группа остановилась | Средняя | Доступ к приватным материалам |
| Компактная навигация по непрочитанным ответам | Вернуться в содержательную часть длинного обсуждения | Средняя | Корректность watch/read cursor |
| Предпросмотр точной цитаты перед переходом | Сохраняет контекст публикации и книги | Средняя | Не подменять точный anchor приблизительным |

Это предложения, а не обещание реализованных функций. Полная смена paper/ink/rust стилистики не требуется.

## Выполнено при подготовке релиза 24 октября

Встроенные ссылки на книги теперь показывают название/автора и справку по hover или явной кнопке; мобильная справка открывается dialog с переходом к книге. Отдельные book blocks сохранены. Цитата раскрывает полный текст, копируется с точным источником, открывает комментарии публикации, переносится в существующий редактор канала и показывает только доступные пометки с совпадающим anchor. Старая textVersion при переносе сохраняется. Похожие фрагменты и старые координаты не подставляются автоматически. Проверены 320/390/768/1024/1440, keyboard и reduced motion; это Chromium, не физические Safari/Android. Голосовые в текущий release scope не включались.
